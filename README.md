# game_analytics
Este proyecto está realizado por Miguel Bedmar Diaz de la Serna Alumno cursando actualmente  segundo del grado superior de Desarrollo de Aplicaciones Multimedia en el centro Ilerna Sevilla.

# 📋DESCRIPCION
En este proyecto una empresa fictisia llamada game-analytics me ha encargado realizar un programa en  pyhton que se encargue de transformar su fichero.csv con datos inconsistentes de su análisis de diferentes fuentes , en otro
con  los datos normalizados para ello se le ha pedido a la inteligencia artificial Claude que genere ese fichero.csv con 50 registros.

# OBJETIVO
El objetivo de este proyecto seguir practicando con python en un supuesto entorno de manejos de archivos y aprender a manejar las diferentes
excepciones que se puedan crear a lo largo del programa.
